# Ad Moderation System (аналог модерации Авито)

Небольшое веб-приложение для просмотра и модерации пользовательских объявлений: просмотр карточек, навигация, фильтрация, галерея изображений, одобрение/отклонение и история модерации.

## Запуск проекта

### 1. Клонирование репозитория
```
git clone https://github.com/Reu04/AdModeration.git
cd AdModeration
```
### 2. Запуск сервера (backend)
```cd avito-proj-server```

```npm install```

```npm start```

Сервер будет доступен по адресу:
`http://localhost:3000`

### 3. Запуск клиента (frontend)

В новом терминале:

```cd avito-proj```

```npm install```

```npm run dev```

Проект будет доступен по адресу:
`http://localhost:5173`

## Используемые технологии

- **React + TypeScript** — удобная разработка интерфейса и типизация.

- **Vite** — быстрый сборщик, мгновенный запуск проекта.

- **SCSS** — удобная стилизация с переменными и миксинами.

- **React Router** — навигация между страницами и объявлениями.

- **react-loader-spinner** — аккуратные лоадеры.

Эти технологии выбраны для ускорения разработки, повышения стабильности и удобства поддержки интерфейса.
